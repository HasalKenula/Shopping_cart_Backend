# 🛒 Online Shopping Cart System

## 📌 Project Overview
The Online Shopping Cart System is a web-based application that allows users to browse, select, and purchase items from multiple categories such as vegetables, fruits, cakes, biscuits, and more. The system supports secure authentication and dynamic cart management for a smooth shopping experience.

---

## 🎯 Purpose
The purpose of this project is to develop a user-friendly e-commerce platform that enables users to:
- Browse products by categories
- Add items to a shopping cart
- Manage cart items (update/delete)
- Calculate total price dynamically
- Use secure authentication methods

---

## 📦 Features

### 👤 User Features
- User login using Google, Facebook, or Passkey authentication
- Browse products by categories
- View product details (image, name, price, description)
- Add products to cart
- Update quantity or remove items from cart
- View real-time total price updates

### 🛠 Admin Features (Optional)
- Add new products
- Edit existing products
- Delete products
- Manage product categories

---

## 🏗 System Architecture

- **Frontend:** React
- **Backend:** Node.js 
- **Database:**  MongoDB
- **Authentication:** Google OAuth


---

## 📋 Functional Requirements

1. **User Authentication**
   - Login via Google
   - Separate admin login

2. **Product Management**
   - Display products by categories
   - Each product includes image, name, price, and description

3. **Shopping Cart**
   - Add items to cart
   - Modify quantity
   - Remove items
   - Auto update total price

4. **Checkout (Future Scope)**
   - Order summary before payment

5. **Admin Panel**
   - Manage products and categories

---

## ⚙️ Non-Functional Requirements

- **Security:** OAuth-based authentication for secure login
- **Performance:** Supports at least 100 concurrent users
- **Usability:** Simple and responsive UI
- **Reliability:** Proper error handling and data backup

---

- **Backend:** REST API / Server-side application
